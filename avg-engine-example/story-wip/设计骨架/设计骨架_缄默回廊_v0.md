## 2. 角色体系（纯文字，不出图）— 修订：补苏岚动机、明确知情范围
| 角色 | 身份 | 与主线关系 | 立绘需求 |
|---|---|---|---|
| **你（玩家代入）** | 新来的心理咨询师，填补 vacancy；**主动应聘**（受父母遗留线索指引，怀疑此院与当年父母失踪有关） | 调查者；独处场景多 → 走 CG/空镜 | 无 |

| **苏岚** | 护士长，三十出头，眉间淡疤 | **当年是言霜的护理员兼挚友**；护短而非共谋，故既守规又泄密、又交物证。红鲱鱼 H2 | 有 |
| **言溪 / 言霜** | 长期住院病人，实为言霜本人（女扮男装 / 新身份壳） | 反转2 核心；被顾承所护、被苏岚所惜 | 有（同一人两态：言溪态 / 言霜态） |
| **老K** | 院外旧案关联人（当年渔夫/值班员） | 红鲱鱼 H3（编造外部凶手证词）；**独立功能**：他也在私下追查当年真相，与你有微妙对抗（P2 待扩写） | 有（少） |

> **知情范围（一致性底线，L-02）**：顾承 + 苏岚 20 年来知晓"言溪=言霜"并共同掩护；全院其他人口径统一为"言霜走入海中失踪"。你逐步逼近，最终由言霜/物证揭穿。
> 关系网：你靠对话积累 `trust_g/s/y`；`clue` 来自档案/海滩/旧物；`san` 因误信红鲱鱼下降（可选）。

## 3. 变量机制（已闭合）— 修订：定义阈值与 gate
| 变量 | 含义 | 阈值 / 作用（明确 gate） |
|---|---|---|
| `clue` | 线索数 | 6 条可达线索（见 §5 表），**≥6** 进入真/隐藏结局判定门槛 |
| `trust_s` | 对苏岚信任度 | **≥2** → Ch9 苏岚交出"物证袋"（真/隐藏结局必需钥匙）；不足则不交 |
| `trust_g` | 对顾承信任度 | **≥2 且 `clue<6`** → 触发**误判结局**（你信了 H1，错告顾承） |
| `trust_y` | 对言溪/言霜信任度 | **≥2** → Ch10 言霜主动坦白身份；低 → 仍可由旧照+物证推断，但路径更硬 |
| `found_parent` | 隐藏触发 flag | Ch11 找到父母遗留记者证物 → 置 1（隐藏结局钥匙） |
| `san` | 理智值（可选） | 误信老K 证词 −；过低强化误判倾向 |

引擎 `set` 仅 `'=' | '+=' | '-='`，无 `'add'`。

## 4. 分支结构（多层反转拓扑）— 修订：反转1/2 统一
- **表层谜底（前 3 章立起）**：20 年前病人言霜"走入海中失踪"，判意外，全院缄口。
- **红鲱鱼（误导）**：
  - H1：顾承掩盖谋杀（看似）。
  - H2：苏岚知情不报、态度暧昧（看似帮凶）。
  - H3：老K 的"当年目击证词"指向外部凶手（编造，但 Ch6 给足"可信外壳"）。
- **反转1（Ch7，中段）**：顾承坦白——他"隐瞒"的是：20 年前院方要把言霜送进"不该去的地方"（非法实验/收容），他**把言霜藏进本院，伪造失踪，给她"言溪"这个新身份**。H1 破：他是在保护，不是掩盖谋杀。
- **反转2（Ch10，后段）**：言溪就是言霜；性别与身份是她藏身的壳；"走入海中失踪"是假死脱身的戏。*（反转1 与 反转2 由此合一：顾承护的人，正是以言溪之名活到今天的言霜。）*
- **隐藏层（Ch11，隐藏结局）**：你找到父母遗留的记者证物，才知你**主动**应聘本就是追查——你父母 20 年前作为调查记者在此"失踪"（与言霜同源的黑幕）。疗养院的非法实验黑幕浮出。
- **汇聚点**：Ch10–11 各线收回主线，Ch12 结局判定前统一清算 `clue` + `trust` + `found_parent`。

## 5. 结局设计（4 个，用 `unlock` 注册）— 修订：gate 明确 + 线索 6 条可达
| 结局 | 触发条件（闭合） | 走向 |
|---|---|---|
| 真结局 `ending_true` | `clue≥6` 且 `trust_s≥2`（拿到苏岚物证袋）且 `found_parent=0` | 揭穿实验黑幕，言霜身份与假死揭弊曝光 |
| 误判结局 `ending_wrong` | `trust_g≥2` 且 `clue<6` | 信了 H1，错告顾承，真相永埋 |
| 隐藏结局 `ending_hidden` | `clue≥6` 且 `trust_s≥2` 且 `found_parent=1` | 真结局 + 父母当年命运揭晓（更深一层） |
| 普通结局 `ending_normal` | 未达上述（含中途离开 / `clue<6` 且无误判触发） | 案未破，你离开回廊 |

**6 条可达线索（对应 `clue` 计数，已确认无缺口）**：
1. 外诊签字件（Ch4）— 顾承口径矛盾
2. 银镯·刻"霜"（Ch6）— 言霜故意留的指向性线索（动机已补：她留作"给懂的人"）
3. 老K 证词矛盾点（Ch6）— 可辨伪，破 H3
4. 言溪≈言霜旧照（Ch8）— 身份疑点
5. 苏岚物证袋（Ch9）— 真/隐藏结局钥匙（`trust_s≥2` 才拿到）
6. 父母记者证物（Ch11）— 同时置 `found_parent=1`，开启隐藏层

> 注：第 6 条既是线索也置隐藏 flag；隐藏结局 = 真结局的超集路径。
