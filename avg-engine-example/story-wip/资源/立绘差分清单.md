## 量化依据

- 引擎真实结构（`game-engine.ts:337` + `types.ts`）：`manifest.sprites` 是 `Record<charId, Record<poseKey, url>>`，**只按 pose 键位换图**；`expression` 字段不参与换图（仅对话样式）。
- 教训（story3《樱色未央》实测）：97 条 `char` 指令中 63% 是换表情——全程一张 default = 角色"面瘫演完整部戏"。故**反查分镜每个角色的「动作/表情」列，逐条落成 pose_key**，不抄摘要里的 default。
- 本作反查结果：4 个显式出立绘的角色（顾承/苏岚/言溪/老K），分镜原文仅标注 **1 个非 default pose = `yanshuang`（言霜态，反转2）**。其余均为 default（温开水笑/握手/递册/立暗/坐/抬眼等可用 default + anim 叠加表达）。

## 出图工艺（引用 G1）

1. **先 S0（§2.5）**：新游戏必须重跑 S0（风格词 + 模型选型 + Style Block 三段），**禁止沿用《雾港回声》风格词/参数**（混用=漂移主因）。产出 `story-wip/素材/style_block_jianmo.md`。
2. **L0 四宫格（§3）**：每角色 1 张 2048×1024（脸特写|正面|左侧面|背面），白底。z-image-turbo 走 **img2img 初值法**（denoise 0.55~0.7）。→ 落 `story-wip/素材/ref/{char}_L0_raw.png`。
3. **参考图接入（§9-A）**：最终立绘以 L0 单格（正面全身/脸特写）当 img2img init；表情变体 denoise 0.55~0.60，不同 pose 0.65~0.70。
4. **身高基线（§8 检 6）**：统一 ~1000px，alpha 通道量 `top%` 3.5~10、`bottom%`≈99.9（§9-F）。
5. **抠图（§10）**：青幕 `matte_cyan`（`g−r>20 且 b−r>20`），四角 alpha=0、透明占比 36~52% 质检。
6. **一致性验收（§9-E）**：S2 预检 3 张（站立/坐姿/行走）→ 全过再批量；批量抽检 10%，不合格率>20% 整批重调。
