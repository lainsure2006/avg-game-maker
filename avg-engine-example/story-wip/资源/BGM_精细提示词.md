## 📌 即梦（SeedMusic）提示词格式速查

即梦音乐 = **Prompt 2 Song**：输入一段"音乐需求"直接生成歌曲，**歌词和音乐要求不做独立传参，可混在一起写**。两种生成类型：

- **背景音乐**（器乐 BGM）：填「风格描述 + 时长 + 节奏(舒缓/轻快/激昂)」。→ 本文件第 2–6 曲用此类型。
- **人声歌曲**（带唱）：填「歌词(最多 100 字) + 曲风(流行/古风/民谣/摇滚) + 音色(男/女/合唱)」。→ 本文件第 1 曲 `bgm_title` 用此类型。

**推荐公式（可整体粘贴到一个框里）**：
```
语言/主题 + 曲风 + 情绪 + 人声 + BPM/调性 + 乐器 + 歌曲结构 + 歌词 + 不想要的元素
```
**通用模板**：
```
我想要一首[语言/主题]歌曲。
整体风格是[曲风/参考氛围]，情绪是[情绪关键词]。
人声希望是[性别/音色/唱法]。
速度约[ BPM ]，调性/拍号是[可选]。
主要乐器包括[乐器列表]，编曲需要[层次/节奏/空间感]。
歌曲结构+歌词是[前奏、主歌、副歌、桥段、尾奏等]。
不要[不想要的元素]。
```
> 即梦一首通常 ≈ 1 分钟，正好契合你要的 title 长度。歌词若走 UI 的「歌词框」**≤100 字**；若把整段（含风格要求）粘进描述框，则不受此限。

## 全局声音世界观（6 曲共享）
- **核心意象**：潮湿、孤寂、被遗忘、记忆如潮、缓慢逼近的真相。
- **声音配方**：低频铺底（海潮/风噪）→ 稀疏旋律（钢琴/钟琴/大提琴）→ 偶发不协和音（悬疑）。
- **统一禁忌**：明亮大调堆砌、电子舞曲鼓点、廉价"跳吓"音效、过猛混响（title 除外）。
- **参考音色**：潮湿房间钢琴、雾里远钟、旧磁带底噪、大提琴长音。

## 1. `bgm_title` — 标题 / 选择页主题曲（★人声歌曲 · 悠长吟唱 · 约 60s）

- **即梦 UI**：生成类型=`人声歌曲`；曲风=选「国风」或「民谣」里最贴近"空灵治愈"的；音色=`女声`。
- **风格内核**：**悠长的吟唱（long sustained chant）**——不是流行副歌，而是女声贴麦气声、字少腔多、长音延音、尾音拖得很长，像海雾里远远哼唱。
- ⚠️ 这版按你要求把原先的"流行结构带歌词"改成了**吟唱式**：词少、腔多、大量留白与延音。

**① 歌词框（≤100 字，直接粘贴）：**
```
雾 从礁石缝里 醒来
旧楼的灯 还亮着半盏
我们走失的 都还住在岛上
若潮水肯把真相交还 就让名字 落回谁的手掌
```

**② 整体 prompt（若即梦有"风格/描述"框，或你想一次粘完，直接贴这段）：**
```
我想要一首约 60 秒的中文主题曲，用于悬疑叙事游戏《缄默回廊》的标题页与章节选择页。
风格：空灵治愈国风 / 氛围新世纪（Ambient New Age），孤寂中带一丝暖意，像潮水退去后留在沙上的字。
人声：女声，气声、贴麦、空灵飘远；以"悠长的吟唱"为主——长音延音、字少腔多、尾音拖长，像在海雾里远远哼唱，不要流行歌的强拍与段落感。
速度约 60–66 BPM，自由散拍（rubato），D 小调，结尾轻转 D 大调留一缕微光。
乐器极简：远处潮声环境底噪 + 极弱 pad 长音弦乐 + 钢琴稀疏单音分解；不要鼓点、不要电子舞曲节奏。
让女声把上面那几句词用长音悠长地吟唱，词与词之间大量留白与延音。
不要：明亮大调堆砌、电子鼓、跳吓音效、过猛混响、戏腔、rap。
```

> 若你改用 Suno/Udio（更吃英文），可保留 v2 的英文 prompt：`Cinematic ambient pop, melancholic memory-core, female breathy mid vocal (Chinese lyrics), solo piano arpeggio verses, warm string swell chorus, distant glockenspiel, ocean ambience bed, D minor to D major lift, 72 BPM, bittersweet, ~60s, loopable, film title theme`

## 2. `bgm_arrival` — 开篇渡轮/到任（背景音乐 · 舒缓 · 可循环）
**即梦 UI**：生成类型=`背景音乐`；节奏=`舒缓`；时长≈90s（loop 友好）。
**prompt（可直接粘贴）：**
```
孤独渡轮黄昏抵达，低频 drone + 极慢弦乐长音 + 极远处一声闷雾笛 + 海浪底噪；冷、孤绝、带轻微不安；小调，约 60 BPM 自由散拍；留白多，可无缝循环。不要人声、不要鼓点、不要明亮大调。
```

**即梦 UI**：生成类型=`背景音乐`；节奏=`轻快(偏缓)`；时长≈90s。
**prompt（可直接粘贴）：**
```
克制平静的日常调查，新古典轻钢琴 + 轻弦乐垫 + 木管短音点缀；中性不悲不喜，线索处一记钟琴；关系大调/Dorian，约 88 BPM；表面正常下藏半音不安。不要人声、不要激烈节奏。
```

## 4. `bgm_night` — 夜戏/探查（背景音乐 · 舒缓偏暗 · 可循环）
**即梦 UI**：生成类型=`背景音乐`；节奏=`舒缓`；时长≈90s。
**prompt（可直接粘贴）：**
```
夜晚探查与长廊暗调，低频 drone 铺底 + 高音区稀疏钢琴单音 + 低弦乐颤音；压抑紧张、音量压低，留白多、间或长段静默制造悬疑张力；小调，约 72 BPM，可无缝循环。不要人声、不要明显打击乐。
```
> ⚠️ 已修：原版 `突然的静默比音更吓人` 是文学比喻非音乐指令、`频段压低` 是混音术语，均被即梦判"不合格"；改为与 `bgm_arrival` 同款的"情绪形容词 + 具体乐器 + 节奏"写法。

## 5. `bgm_tension` — 悬疑/反转/揭示（背景音乐 · 渐强/激昂 · 可循环）
**即梦 UI**：生成类型=`背景音乐`；节奏=`激昂(渐强)`；时长≈60–90s。
**prompt（可直接粘贴）：**
```
悬疑反转逐步推到临界点，脉动低弦 ostinato + 渐强不和谐铜管/弦 + 急促琶音 + 心跳般定音鼓；中段留 4–6 秒静默再接揭示段落；小调半音阶下行，约 108 BPM 渐快渐强，可无缝循环。不要人声。
```
> ⚠️ 已修：原版 `中段留4–6秒"爆点前静默"接揭示` 中"爆点"偏激烈易触发审核，改为中性表述。
