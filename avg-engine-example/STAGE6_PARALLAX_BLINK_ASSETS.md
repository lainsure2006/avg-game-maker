## 一、视差分层素材（背景多图层）

**规格**：每个场景输出 `fg` / `mid` / `bg` 三张分离 PNG（各自带透明通道），引擎按位移系数叠加平移，营造纵深。
**出图流程**：先用 `krea2-scene-sheet` 出「同场景多角度/多区域参考图」，再分通道裁出各层。
**风格**：《缄默回廊》= 陈旧阴森但仍在运转的荒岛医院（冷青灰、潮湿、设备半朽但通电）。

| 场景 | 落盘路径 | fg 层（前景） | mid 层（中景） | bg 层（远景） |
|------|----------|---------------|----------------|---------------|
| 走廊 corridor | `bg/jianmo/layers/corridor_{fg,mid,bg}.png` | 栏杆 / 吊灯 / 倒地医疗推车剪影 | 墙面色温 / 半开舱门 | 远端尽头发光窗、雾 |
| 大厅 hall | `bg/jianmo/layers/hall_{fg,mid,bg}.png` | 前台 / 破碎玻璃 / 散落病历 | 立柱 / 指示牌 | 远处楼梯与天光 |
| 病房 ward | `bg/jianmo/layers/ward_{fg,mid,bg}.png` | 床架 / 输液架 / 监护仪 | 墙体设备 / 帘 | 窗外海雾 |
| 庭院 courtyard | `bg/jianmo/layers/courtyard_{fg,mid,bg}.png` | 杂草 / 铁椅 / 锈蚀器械 | 地砖 / 排水沟 | 远山与海平线 |

**验收口径**：三层层间留有合理遮挡关系；fg 透明占比高（主体为剪影/前景物），bg 接近全幅；三者尺寸一致（如 1920×1080 或沿用引擎基准 1280×720 整数倍）。

## 二、眨眼 / 微表情素材（角色眼睛独立层）

**规格**：每个角色每个已用姿态（pose）需额外输出「睁眼层」与「闭眼层」两张透明 PNG（仅眼睛区域，与立绘**同尺寸同坐标**），引擎运行时叠加，定时器触发眨眼（睁→闭→睁）。
**出图流程**：用 `krea2-persona-sheet` 风格出图时，额外要求「眼睛单独成层 / 可分离」，或用 inpaint 单独重绘闭眼帧。

**候选角色**（先覆盖《缄默回廊》4 主角——已交付 9 张新 sprite）：

| 角色 | 已有 sprite 姿态 | 需补眼睛层（每姿态 × 睁/闭） | 落盘路径 |
|------|------------------|------------------------------|----------|
| 顾承 gucheng | default / serious / calm / sad（4） | 8 张 | `sprite/gucheng/eyes/{pose}_eyes_{open,closed}.png` |
| 苏岚 sulan | default / serious（2） | 4 张 | `sprite/sulan/eyes/{pose}_eyes_{open,closed}.png` |
| 言溪 yanxi | default / serious（2） | 4 张 | `sprite/yanxi/eyes/{pose}_eyes_{open,closed}.png` |
| 老K laok | default（1） | 2 张 | `sprite/laok/eyes/default_eyes_{open,closed}.png` |

**命名**：`<char>_<pose>_eyes_open.png` / `<char>_<pose>_eyes_closed.png`
**验收口径**：睁/闭眼层与对应 sprite 像素对齐（坐标偏移 ≤ 2px）；闭眼层为自然闭合（非眯眼）；透明区域仅含眼部。

## 三、开机出图流程（待用户确认开机后执行）

1. 用户开机 AutoDL：`ssh -p 24441 root@connect.nmb2.seetacloud.com`（ComfyUI 端口 6006）。
2. AI 经 comfy-mcp 跑：
   - `krea2-scene-sheet` → 背景分层（走廊/大厅/病房/庭院）；
   - `krea2-persona-sheet`（改造版，要求眼睛分层）→ 角色眼睛层。
3. 数字验收（透明占比 / ArcFace 相似度 ≥0.70 / 像素对齐）后交付，注册进对应 `manifest.ts`。
4. 引擎接入：`scene` 多层渲染（fg/mid/bg 位移系数）+ `CharacterState.blink` 计时（随机间隔叠加闭眼层）。

## 四、替代 / 降级方案（成本权衡）

- **视差降级**：若分层出图成本高，可先用「单图 + 程序化视差」——整图按深度伪分层平移（近景位移大、远景小），无需新素材，但纵深感弱于真分层。
- **眨眼降级**：可暂用「整张 sprite 轻微纵向缩放」模拟呼吸/眨眼，但无真闭眼帧，效果弱；仅作过渡。
- 二者均可先以降级跑通引擎链路，等开机出真素材后再替换。
